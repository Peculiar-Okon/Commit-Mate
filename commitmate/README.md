# CommitMate - AI Git Copilot

An AI-powered Git commit message generator for developers. CommitMate analyzes your staged changes and generates meaningful, conventional commit messages using AI.

## Features

- 🤖 AI-powered commit message generation
- 📝 Follows conventional commit format
- ⚡ Fast and lightweight
- 🔧 Configurable AI providers

## Requirements

- VS Code 1.125.0 or higher
- Git installed and configured
- An API key for your chosen AI provider

## Usage

1. Stage your changes using `git add`
2. Open the Command Palette (`Ctrl+Shift+P`)
3. Run the **generateCommit** command to test the extension

## Extension Settings

This extension contributes the following settings:

* `commitmate.enable`: Enable/disable the extension.
